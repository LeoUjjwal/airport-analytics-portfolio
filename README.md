# ✈️ Airport Analytics Dashboard

An interactive airport analytics dashboard built with **Python, Pandas, Plotly, and Streamlit** to explore airport data through visualizations, geographic mapping, and data-quality insights.

🔗 **Live Dashboard:** [[View the Airport Analytics Dashboard](YOUR_STREAMLIT_APP_URL)](https://airport-analytics-portfolio.streamlit.app/)

📂 **GitHub Repository:** https://github.com/LeoUjjwal/airport-analytics-portfolio

## 📊 Project Overview

This project transforms airport records into an interactive dashboard that helps users explore airport distribution, compare countries, and examine airport data through charts, filters, and a geographic map.

The project demonstrates practical skills in data handling, exploratory data analysis, data visualization, and dashboard development.

## ✨ Key Features

- **Interactive Dashboard:** View key metrics and summaries of the airport dataset.
- **Search and Filtering:** Explore airport records using available search fields and filters.
- **Geographic Visualization:** View airport locations on an interactive map using latitude and longitude.
- **Data Visualization:** Explore airport distributions through interactive charts.
- **Airport Directory:** Browse airport records in a tabular format.
- **Data Export:** Download airport data for further analysis.
- **Data Quality Insights:** Examine airport-code completeness and potential duplicate codes, where included in the current dashboard.

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/LeoUjjwal/airport-analytics-portfolio.git
cd airport-analytics-portfolio
```

### 2. Create and activate a virtual environment

Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Launch the dashboard

```bash
python -m streamlit run app.py
```

Open the local URL displayed in the terminal, usually `http://localhost:8501`.
